# DPSynth 0.1.0

* Initial CRAN submission.

* Features:
  - DP-Copula synthesizer (`dp_copula_synth`) for mixed numeric/categorical data
  - DP-GMM (`dp_gmm_synth`) using perturb-and-postprocess paradigm
  - DP marginals (`dp_marginals_synth`) for fast baseline synthesis
  - PATE (`dp_pate_synth`) for discrete/mixed-type data
  - Utility evaluation (`evaluate_utility`) with univariate, multivariate, propensity pMSE, and downstream metrics
  - Risk auditing for membership inference, attribute disclosure, and record linkage
  - Privacy budget accounting with basic, advanced, and Rényi DP composition
